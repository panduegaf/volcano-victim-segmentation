First of all, photos of real volcanic disaster victim collected from online news and other website. Those photos then used as dataset. The dataset filtered with several edge detection methods. In this experiment, there are 14 filters of edge detection: Canny, Laplacian, Prewitt X, Prewitt Y, Prewitt Combined, Sobel X, Sobel Y, Sobel Combined, Roberts X, Roberts Y, Roberts Combined, Scharr X, Scharr Y, and Scharr Combined. Since the dataset have various sizes and lacking, preprocessing and data augmentation is performed. Then, the dataset separated into training and testing data. The training data inputted into YOLO11s train model with epochs 100. Lastly, the final models are ready to test on testing data. Overall framework is shown in Fig. 1.

In this study, a total of 14 edge detection filters were evaluated. These filters include Canny and Laplacian, alongside directional and combined implementations of the Sobel, Prewitt, Roberts, and Scharr operators. Specifically, the designations 'X' and 'Y' denote filters that utilize the horizontal and vertical derivative approximations, respectively, while the 'Combined' designation refers to the merging of results from these two directional approximations. The specific configuration for each filter is implemented using the OpenCV library (cv2) in the Python programming language. The configuration details are as follows:
1)  	Canny: The Canny filter implementation uses the cv2.Canny(img, 100, 200) function, with adjustable lower and upper threshold values to optimize edge detection.
2)  	Laplacian: The Laplacian filter is implemented using the cv2.Laplacian(img, cv2.CV_64F, ksize=5) function with a kernel size of 5x5 to detect sharp pixel intensity changes. The absolute result is also converted using cv2.convertScaleAbs().
3)  	Sobel: The Sobel filter is applied to detect edges in the horizontal (X) and vertical (Y) directions using the cv2.Sobel(img, cv2.CV_64F, 1, 0, ksize=5) and cv2.Sobel(img, cv2.CV_64F, 0, 1, ksize=5) functions with a kernel size of 5x5. The absolute result of the convolution is then converted back to 8-bit unsigned integer format using cv2.convertScaleAbs(). The results from the X and Y directions are then combined using cv2.addWeighted() with equal weights (0.5).
4)  	Prewitt: The Prewitt filter is implemented manually using a convolution kernel. The absolute results are converted with cv2.convertScaleAbs() and then combined using cv2.addWeighted() with a weight of 0.5 for both directions.
The proposed methodology was validated using a dataset of 20 images depicting volcano victims (shown in Fig. 2). To mitigate the risk of overfitting and increase data diversity, the initial dataset underwent an augmentation process. This process involved the application of several transformations, specifically: horizontal and vertical flips, random rotations (up to 30 degrees), random adjustments to brightness and contrast, and Gaussian blur. Consequently, the dataset was expanded to 80 images. Prior to training, all images were normalized within the range of [0, 1].
The images that have been processed using various edge detection filters are then fed into the YOLO11s. This model was trained with the following configuration: the two classes of objects trained by the model are “Victim” and “Nonvictim”, the number of epochs (training iterations) was 100, the image size (imgsz) used as input was 640x640 pixels, and the Intersection over Union (IoU) threshold for non-maximum suppression (NMS) is set at 0.5.
